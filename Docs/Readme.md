# PowerBGInfo Module
## Description
PowerBGInfo is a module that allows you to create background images with information about your environment.

## PowerBGInfo Cmdlets
### [Export-BGInfoConfiguration](Export-BGInfoConfiguration.md)
Exports a BGInfo configuration to JSON.

### [Get-BGInfoSystemInfo](Get-BGInfoSystemInfo.md)
Returns read-only facts about this machine as one plain object.

### [Invoke-BGInfo](Invoke-BGInfo.md)
Runs BGInfo from a JSON configuration file.

### [Invoke-BGInfoDataSource](Invoke-BGInfoDataSource.md)
Runs your data-collection code with a time limit and a fallback value.

### [New-BGInfo](New-BGInfo.md)
Creates a BGInfo overlay image and optionally applies it as wallpaper.

### [New-BGInfoBackground](New-BGInfoBackground.md)
Creates a generated backdrop that replaces the wallpaper image.

### [New-BGInfoBackgroundGlow](New-BGInfoBackgroundGlow.md)
Creates a soft radial light for New-BGInfoBackground.

### [New-BGInfoCalendarHeatmap](New-BGInfoCalendarHeatmap.md)
Creates a calendar heatmap panel: one cell per day, darker for larger values.

### [New-BGInfoChart](New-BGInfoChart.md)
Creates a BGInfo chart definition.

### [New-BGInfoConfiguration](New-BGInfoConfiguration.md)
Creates a BGInfo configuration object.

### [New-BGInfoImage](New-BGInfoImage.md)
Creates a BGInfo image overlay definition.

### [New-BGInfoLabel](New-BGInfoLabel.md)
Creates a BGInfo label entry.

### [New-BGInfoLayout](New-BGInfoLayout.md)
Sets the safe area and region sizes that -Region panels flow into.

### [New-BGInfoList](New-BGInfoList.md)
Creates a list panel: bullets, numbers, a checklist or status rows.

### [New-BGInfoMermaid](New-BGInfoMermaid.md)
Creates a diagram panel from Mermaid text, for example an escalation path or a network flow. Pipeline lines are joined before rendering.

### [New-BGInfoMetric](New-BGInfoMetric.md)
Creates a KPI panel: label, value, trend, status and optional history.

### [New-BGInfoQRCode](New-BGInfoQRCode.md)
Creates a QR code panel, for example a link to the help-desk portal.

### [New-BGInfoTable](New-BGInfoTable.md)
Creates a table panel from objects or explicit rows.

### [New-BGInfoTheme](New-BGInfoTheme.md)
Creates a wallpaper theme: text, panel, status and backdrop colors plus spacing and type scale.

### [New-BGInfoTimeline](New-BGInfoTimeline.md)
Creates a timeline panel: ranges on named lanes, with a Now marker.

### [New-BGInfoTimelineItem](New-BGInfoTimelineItem.md)
Creates one range for New-BGInfoTimeline.

### [New-BGInfoTopology](New-BGInfoTopology.md)
Creates a BGInfo topology overlay definition.

### [New-BGInfoTopologyEdge](New-BGInfoTopologyEdge.md)
Creates a BGInfo topology edge definition.

### [New-BGInfoTopologyGroup](New-BGInfoTopologyGroup.md)
Creates a BGInfo topology group definition with bounds sized automatically around its members.

### [New-BGInfoTopologyNode](New-BGInfoTopologyNode.md)
Creates a BGInfo topology node definition.

### [New-BGInfoTreemap](New-BGInfoTreemap.md)
Creates a treemap panel: sizes as nested rectangles, for example disk usage by folder or VM.

### [New-BGInfoValue](New-BGInfoValue.md)
Creates a BGInfo value entry.

### [New-BGInfoVariable](New-BGInfoVariable.md)
Creates a reusable BGInfo variable backed by a built-in provider.

### [New-BGInfoVisualCanvas](New-BGInfoVisualCanvas.md)
Creates a BGInfo visual canvas definition backed by ChartForgeX.

### [New-BGInfoVisualCanvasFeature](New-BGInfoVisualCanvasFeature.md)
Creates a BGInfo visual canvas feature-strip item.

### [New-BGInfoVisualCanvasTile](New-BGInfoVisualCanvasTile.md)
Creates a BGInfo visual canvas tile definition.
