Canonical site: https://powerbginfo.com/

- [Documentation](https://powerbginfo.com/docs/): PowerBGInfo installation, layouts and deployment.
- [Examples](https://powerbginfo.com/examples/): configuration and deployment examples.
- [Gallery](https://powerbginfo.com/gallery/): real wallpaper renders and their recorded source scripts.
- [Build a wallpaper](https://powerbginfo.com/build/): step-by-step rendering with sample data.
- [Platforms](https://powerbginfo.com/platforms/): released support and preview capabilities.
- [DesktopManager](https://powerbginfo.com/desktopmanager/): desktop control tools.
- [InformationBox](https://powerbginfo.com/informationbox/): Windows self-service application; AGPL-3.0, first release pending.

PowerBGInfo is MIT licensed. DesktopManager is a separate MIT project. InformationBox is a separate AGPL-3.0 project. macOS and Linux PowerBGInfo support stays Preview until released. Rendered samples contain illustrative data, not live machine telemetry.
