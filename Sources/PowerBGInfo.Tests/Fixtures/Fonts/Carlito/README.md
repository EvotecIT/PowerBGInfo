# Carlito review fixtures

These unmodified regular and bold fonts are test-only fixtures for PowerBGInfo canvas typography. They are embedded in the test assembly and are not included in the product or module. The typography fixture registers them within a nonparallel xUnit collection and removes the registrations after rendering, so scale assertions use the same faces on Windows, macOS, and Linux.

Source: [Google Fonts Carlito at revision 3dd78844021e948ceb633d1dcee3f7885561b5d9](https://github.com/google/fonts/tree/3dd78844021e948ceb633d1dcee3f7885561b5d9/ofl/carlito). The font copyright and SIL Open Font License 1.1 are retained in [OFL.txt](OFL.txt).
